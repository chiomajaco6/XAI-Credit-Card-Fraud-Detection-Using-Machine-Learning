# 💳 Credit Card Fraud Detection Using Machine Learning

## 📌 Project Overview
This project focuses on building a machine learning-based fraud detection system capable of identifying fraudulent credit card transactions using historical transaction data. The system applies data preprocessing, class imbalance handling, exploratory data analysis, and multiple machine learning models to achieve accurate fraud classification.

📊 **Dataset Source:**  
[Kaggle Credit Card Fraud Dataset](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)

---

## 🎯 Aim
To develop a machine learning-based fraud detection system capable of identifying fraudulent credit card transactions using historical transaction data.

---

## 🧠 Specific Objectives

- To collect and preprocess credit card transaction data for analysis.
- To handle class imbalance using techniques such as SMOTE or undersampling.
- To perform exploratory data analysis (EDA) to understand transaction patterns.
- To identify key features that distinguish fraudulent from legitimate transactions.
- To build and train machine learning models such as Logistic Regression, Random Forest, and Decision Trees.
- To evaluate model performance using precision, recall, F1-score, and ROC-AUC metrics.
- To compare different models and select the best-performing algorithm.
- To deploy a simple prediction system for fraud detection.
- To interpret model results for explainability and decision support.
- To demonstrate practical application of machine learning in financial security.
